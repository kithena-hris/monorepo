Reach Mobile · Forms

Field

The wrapper for every form control: the label above, the control, then a hint or an error below it. Only one message shows at a time.

Input

The bare text control. Use it inside Field unless it labels itself, as a search box does.

NumberField

For counts and amounts. Empty means no value, and it never turns into 0 by itself.

PasswordField

Masked by default with a reveal button. Always allow pasting, so password managers work.

PinInput

One box for each character. Typing moves to the next box, and pasting fills every box at once.

TagsInput

A free list of short values, like skills or email addresses. Enter or a comma adds a tag. Backspace in an empty input removes the last one.

Rating

Pick a whole number from 1 to 5. Always say what each number means, because a star alone is ambiguous.

Select

Pick one value from a short, fixed list. Over about 10 options, use Combobox instead.

Combobox

Type to filter a long list. Matches are highlighted, and Enter picks the first one.

Checkbox

For turning options on or off as part of a form you then save. For a setting that applies straight away, use Switch.

RadioGroup

Pick exactly one of two to five options when everyone needs to see the choices side by side.

Switch

For a setting that applies the moment you flip it. If it takes a moment, show a spinner and roll back if it fails.

Toggle

A button that stays pressed. Use it for view options and formatting, not for settings.

Slider

For picking a rough value where the range matters more than the exact number. Pair it with a number input when the exact value matters.

Calendar

A month grid for picking days. It shows leave, holidays and blocked days so you don’t have to guess.

DatePicker

A field that opens a calendar. You can always type the date instead.

Typed fields

Fields for a specific kind of value. Each one brings the right keyboard, format and checks.

ImageUploader

Upload images with a preview. It checks size and file type before uploading, and says exactly what went wrong.

Dropzone

A large target for dragging files onto. Clicking it always opens the file browser too.

RichTextEditor

Formatted text for policies, notes and comments. It stores safe HTML and reads it back the same way.

FileUploader

Upload documents with a row for each file. Each row shows progress, lets you retry, and says why a file was refused.

TimePicker

Pick a time with the system wheel. You can type the time with a hardware keyboard.

Form sections

How long forms are laid out: titled sections, one column on phones, and a save bar that only appears once something has changed.
