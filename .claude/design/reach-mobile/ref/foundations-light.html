Reach Mobile · Foundations

Tokens

The named values every component is built from. Use the semantic names, never raw colours.

Motion

Motion is calm and explains where things came from. It is always optional and turns off under reduced motion.

Responsive

One product, many screens. Layout changes at breakpoints; tokens and components do not.

Patterns

Whole screens that combine components. Copy these before inventing something new.

App marks

The Reach app icon. Always the squircle, never stretched, never recoloured outside the palette.

Brand

The lockup pairs the mark with the wordmark set in the display face.

Typography

SF Pro on iOS and Roboto Flex on Android, set by the system. Body text is 17.

Icons

Lucide, drawn at a 2px stroke. Icons support labels. They don’t replace them.

Layout presets

Mobile screens follow one shell: status bar, top bar, large title, content, and a floating tab bar.

Hierarchical layout

List and detail. Wide screens show both. Narrow screens push the detail on top of the list.

Modal page

A task that takes over the screen until it’s done or cancelled: onboarding, a new request, an import.

Layout primitives

Stack, Inline, Split, AutoGrid and Container. They handle spacing, so components never set their own margins.

Scroll area

For fixed-height regions only. Page-level scroll is always the browser’s.

Separator

A hairline between groups. Try spacing first.
