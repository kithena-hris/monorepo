# Project rules
- AI chat (Ask Kithena) is a small floating window anchored to the launcher (web ~400×580, bottom-right; mobile: a compact card above the tab bar). Never full-screen or full-height, no scrim; the app behind stays usable.
- Prefer centred modals over side/bottom sheets for short, focused tasks (filters, confirmations, small forms). Sheets only for long, scrolling editors that need the page as context.
